# Contributing

1. Open an issue for behavior changes or new compatibility profiles.
2. Keep the deterministic core small and platform-neutral.
3. Add tests for every alias, diff, transaction, adapter, or proxy behavior changed.
4. Never use a personal production gateway in tests; use fixtures or a local mock server.
5. Run the Python, Node syntax, proxy, Agent Skill, and secret-scan checks before a pull request.
6. Mark platform/runtime support Verified only with reproducible evidence.

By contributing, you agree that your contribution is licensed under MIT.
